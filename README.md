# Roller Friends

Статичний багатосторінковий сайт ролер-школи Roller Friends в Ужгороді.

## Структура

- `dist/index.html` — головна сторінка;
- `dist/*.html` — сторінки напрямів, правил, цін, абонементів, прокату та команди;
- `dist/*.css` і `dist/*.js` — стилі та клієнтські сценарії;
- `dist/assets/` — шрифти, фотографії, ілюстрації та фонове відео;
- `scripts/validate-site.mjs` — перевірка структури та локальних посилань;
- `vercel.json` — конфігурація Vercel із директорією публікації `dist`.

## Локальна перевірка

Потрібні Node.js 18+ і Python 3.

```bash
npm run validate
npm run dev
```

Після запуску сайт доступний за адресою `http://localhost:4173`.

## Публікація через GitHub і Vercel

1. Створіть порожній репозиторій на GitHub.
2. Додайте його як Git remote і відправте гілку `main`.
3. У Vercel оберіть **Add New → Project** і підключіть GitHub-репозиторій.
4. Vercel прочитає `vercel.json`, запустить `npm run build` і опублікує вміст `dist/`.
5. Після першого деплою перевірте головну сторінку та всі внутрішні посилання на комп’ютері й телефоні.

Сайт не потребує фреймворку, бази даних або серверного коду.
