## Невикористаний файл

`dist/assets/safe.webp` не має посилань у HTML, CSS чи JavaScript. Файл залишено локально та виключено з Git. Він усе ще лежить у `dist`, тому публікація всієї директорії може включити його. Перед використанням на сайті приберіть відповідний рядок із `.gitignore` та додайте файл до Git.

## Резервні копії

Після змін запускайте `npm run validate`. Перед публікацією перегляньте сторінки на комп’ютері й телефоні. Подальше стиснення невеликих зображень необов’язкове.
